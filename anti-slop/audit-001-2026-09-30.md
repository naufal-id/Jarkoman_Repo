## A. Wajib diperbaiki (TINGGI)

**1. Halaman publik bisa tertahan di layar loading.** R-27 · TINGGI
`src/public/App.tsx:68`. Refresh diam dan muat pertama memakai penghitung permintaan yang sama. Kalau tab menjadi terlihat selagi muat pertama belum selesai (misalnya link dari WhatsApp dibuka di latar lalu dipindah ke depan), hasil muat pertama dibuang. Bila refresh itu gagal atau datanya kosong, halaman tidak pernah menampilkan cache offline, data contoh, maupun pesan error.
Perbaikan: refresh diam hanya berjalan saat status `ready`, dengan penghitung sendiri.

**2. Draft admin yang dipulihkan tidak memuat pendaftar web terbaru.** Teknis · TINGGI
`src/admin/Dashboard.tsx:94`. Draft lokal dipulihkan apa adanya, sementara `saved` sudah memuat `joinSeq` terbaru, jadi polling 20 detik menganggap tidak ada yang baru. Admin melihat skuad lama (pendaftar baru tidak tampil, yang sudah batal masih ada) sampai menyimpan. Server tetap menggabungkan saat simpan sehingga data tidak hilang, tapi keputusan admin (mengisi slot manual, broadcast WA) memakai data basi.
Perbaikan: gabungkan saat memulihkan, `applyWebChanges(local.state, base, local.state.joinSeq)`.

**3. Mengganti password admin mematikan semua tombol "Batal ikut".** Teknis · TINGGI
`netlify/lib/auth.ts:14`. Kalau `JARKOMAN_SECRET` tidak diisi, kunci HMAC pendaftar diturunkan dari `ADMIN_PASSWORD`. Begitu password diganti, semua pemain yang sudah daftar mendapat 403 saat batal ikut.
Perbaikan: buat rahasia acak sekali dan simpan di Netlify Blobs sebagai cadangan, dan catat `JARKOMAN_SECRET` di README.

**4. Tiga pasangan warna gagal kontras AA.** R-25 · TINGGI
- `.jf__opt` (label "opsional", `opacity: 0.8`): 3,5:1 di VALORANT Bone, 4,27:1 di R.E.P.O. Lampu nyala.
- `#val-join-title > .val-title__index` (nomor judul form): 4,26:1 di VALORANT Bone.
Perbaikan: warna token eksplisit per tema, bukan opacity.

**5. Header VALORANT meluap 13 px di layar 320 px.** R-03 · TINGGI
`.val-top__share` mendorong halaman bergeser horizontal di HP kecil dan saat zoom teks.

**6. Fokus keyboard tidak terlihat di dashboard.** R-32 · TINGGI
Input tanggal/jam dan iframe preview tidak menampilkan indikator fokus. Admin yang memakai keyboard kehilangan posisi.

**7. Pratinjau link WhatsApp masih menjanjikan alur lama.** R-38, R-20 · TINGGI
Keempat gambar `public/og/*.jpg` bertuliskan "Konfirmasi via WhatsApp/WA", begitu juga meta description di `index.html:10` dan `index.html:14`, padahal bawaan sekarang LOCK IN langsung masuk skuad. Gambar OG MLBB masih memakai Cinzel yang sudah diganti Oswald. Ini hal pertama yang dilihat orang di grup WA. Edge function sudah menyesuaikan teks deskripsi per jarkoman; yang tertinggal gambar dan fallback statis.
Perbaikan: render ulang 4 gambar OG dengan copy yang benar untuk kedua mode (misalnya "Cek slot · Tekan LOCK IN") dan tipografi terbaru.

## C. Teknis

**12. LCP lambat di semua tema (render delay 3,4–4,4 detik).** Teknis · SEDANG
Rantainya: HTML → JS utama → `/api/state` → chunk tema (lazy) → gambar key art, lalu GSAP memudarkan gambar LCP dari opacity 0.
Perbaikan: edge function (yang sudah tahu jarkoman unggulan untuk OG) menyisipkan `<link rel="preload">` untuk key art dan chunk tema; permintaan state dimulai sejak `<head>`; intro gambar hero memakai clip/scale tanpa opacity 0. Target performa mobile ≥ 85.

**13. MLBB Total Blocking Time 1.050 ms (skor 57).** Teknis · SEDANG
`src/public/themes/mlbb/Embers.tsx:55`: `shadowBlur` dihitung untuk setiap partikel di setiap frame.
Perbaikan: pra-render satu sprite bara bercahaya ke canvas offscreen lalu `drawImage`; partikel lebih sedikit di HP; DPR dibatasi 1,5. Tampilan sama, biaya jauh lebih kecil.

**14. Belum ada CI dan test end-to-end di repo.** Teknis · SEDANG
Typecheck, 50 unit test, build, dan QA Playwright 16 kombinasi hanya dijalankan manual dari sesi kerja. Tidak ada `.github/` dan tidak ada konfigurasi Prettier (gaya kutip dan titik koma campur, misalnya `JoinForm.tsx` beda dengan file lain).
Perbaikan: GitHub Actions `typecheck + test + build` di setiap push; skrip QA (overflow 320/360 px, alur LOCK IN → Batal ikut, axe) dipindah ke `tests/e2e`; tambah `.prettierrc`.

**15. Pendaftaran web mudah di-spam.** Teknis · SEDANG
Siapa pun yang punya link bisa mengisi sampai 20 nama palsu; perlindungan saat ini hanya kolom jebakan bot.
Perbaikan: batas per IP (hash, disimpan di Blobs, misalnya 3 pendaftaran per 10 menit per jarkoman), tombol admin "hapus semua pendaftar web", opsi mode "perlu persetujuan host".

**16. "Catatan untuk host" ternyata publik.** Teknis · SEDANG
Label form menyebut catatan untuk host, tapi `GET /api/state` tanpa login mengembalikan `note` setiap pemain ke siapa saja.
Perbaikan: buang `note` dari respons publik dan kirim hanya ke admin yang login, atau ubah labelnya menjadi "terlihat semua orang".

**17. Belum ada Content-Security-Policy.** Teknis · RENDAH
`netlify.toml` sudah memasang nosniff, Referrer-Policy, dan Permissions-Policy. CSP ketat (`script-src 'self'`, `img-src` untuk domain media yang dipakai, `connect-src 'self'`) menutup kelas XSS di masa depan.
